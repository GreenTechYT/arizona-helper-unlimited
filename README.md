## 📖 О проекте

**Arizona Helper Unlimited** — модификация оригинального Arizona Helper, которая расширяет его возможности и добавляет десятки новых функций для комфортной игры на серверах **Arizona Online** и **Rodina Online**.

Хелпер работает как на **ПК** (Windows), так и на **мобильных устройствах** (Android), поддерживает все основные фракции и предлагает удобный интерфейс с гибкой настройкой под себя. Начиная с версии 1.7.0 хелпер использует систему профилей и требует принятия пользовательского соглашения перед началом работы.

## ✨ Функции

### 🎭 RP-возможности
- **RP общение в чатах** — автоматическая заглавная буква и точка в конце сообщений (работает в `/s`, `/do`, `/f`, `/fb`, `/r`, `/rb`, `/j`, `/jb`, `/fam`, `/al`)
- **RP отыгровка оружия** — реалистичные отыгровки при использовании и скролле оружия
- **RP проверка документов** — автоматический приём и проверка документов из `/offer`
- **Биндер RP-команд** — создавайте и редактируйте собственные RP-отыгровки с поддержкой тегов, задержек и пауз
- **Стандартные RP-команды** — готовые отыгровки для очков ночного видения (`/pnv`), инфракрасных очков (`/irv`) и других действий
- **Криминалистические экспертизы** — настраиваемые отыгровки с отдельным конфигом, поддержка тегов `{pause}` и `{wait(мс)}`
- **Авто-расследование убийств** — автоматическое заполнение даты, времени и орудия преступления

### ⚡ Ассистент
- **Пинг в чате** — звуковое оповещение при упоминании вашего ника
- **Автофлип домкратом** — автоматическое использование `/domkrat` при перевороте авто
- **Переодевание маски** — мгновенная замена слетевшей маски
- **Авто-обновление `/members`** — актуальный список сотрудников с настраиваемым интервалом, сортировкой по столбцам и двухцветной подсветкой AFK
- **Авто-доклады `/post` и `/patrool`** — автоматический доклад в рацию с настраиваемым интервалом (1–30 минут) и собственным редактором текстов
- **Инвайт по фразе [9/10]** — автоматический инвайт игроков, просящих инвайт в чате
- **Увал по ПСЖ [9/10]** — автоматическое увольнение сотрудников по ПСЖ
- **Собеседование `/sob`** — встроенные вопросы и отказы, многострочные ответы, редактор в настройках с вкладками «Вопросы», «Отказы» и «Основное», подстановка `{nick}`, настройка КД между сообщениями

### 🎨 Интерфейс
- **Кастомный ScoreBoard** — замена стандартного TAB-интерфейса на Mimgui-версию с действиями, зависящими от вашей организации (авто-поиск, розыск, штраф, ЭБГО, срок)
- **Кастомный `/members`** — удобный интерфейс списка сотрудников с личными пометками игроков
- **Цветной прицел** — два режима (обычный / при наведении), учёт дальности оружия и легендарной нашивки (+8 к дальности), настройка шрифта надписи дистанции
- **PieMenu** — круговое меню для быстрого вызова команд (СКМ на ПК, кнопка на мобильных) с перемещением пунктов и счётчиком
- **Фаст меню** — быстрое взаимодействие с игроком (`/hm ID`) и лидерское меню (`/lm ID` для 9/10 ранга)
- **Мобильные кнопки** — настраиваемые экранные кнопки для мобильных устройств
- **Хоткеи** — гибкая настройка клавиш для всех основных действий
- **Заметки** — личные заметки и шпаргалки прямо в хелпере с поиском
- **Новости** — двухпанельный вид, поиск по статьям, заголовки, списки, абзацы и система лайков
- **Темы оформления** — Custom (с поддержкой MoonMonet), Dark и White темы, настройка прозрачности и цвета сообщений

### 🛠 Инструменты
- **Пробив по ЭБГО** (`/edgo`) — система пробива личности с настраиваемой задержкой РП и приоритетом по цвету организации
- **Авто-поиск по GPS** (`/afind ID`) — автоматический поиск игрока с отслеживанием местоположения и авто-остановкой при приближении
- **Умная выдача розыска** (`/sum ID`) — удобная система выдачи розыска с запросом офицера
- **Умные штрафы** (`/tsm ID`) — быстрая выписка штрафов
- **Круиз-контроль** (`/cruise`) — адаптивный круиз-контроль для транспорта с авто-стартом и учётом препятствий
- **Список заключённых** (`/zeks`) — кастомный интерфейс списка заключённых (для Правительства) с авто-обновлением
- **Умное повышение срока** (`/pum ID`) — удобная система повышения срока (для Тюрьмы)
- **Список `/wanted`** (`/wanteds`) — автоматическое сканирование списка розыска с настраиваемым интервалом
- **Патрулирование** (`/patrool`) — меню патрулирования с авто-докладами
- **Рация департамента** (`/dep`) — быстрые ответы, настройка тегов и скобок `[]`, компактное окно
- **Спавн транспорта** (`/spcar`) и **увал неактивных** (`/fcleaner`) — лидерские инструменты (9/10 ранг)

### 💾 Данные и стабильность
- **Система аккаунтов** — несколько профилей для разных персонажей с мгновенным переключением и автоматической миграцией данных со старых версий
- **Резервные копии** — опциональные бэкапы настроек, модулей и файла хелпера в папке `Backup`, отдельно для каждого аккаунта; выбор категорий и модулей, ручное создание и автовосстановление повреждённых файлов
- **Библиотеки** — система копий (`arizona_backup.lua`) и обработчик ошибок (`arizona_crasher.lua`) вынесены в отдельные библиотеки с автообновлением и фолбэком на локальные версии при недоступности GitHub
- **Уведомления** — гибкая настройка сообщений в чат, сгруппированных по организациям (полиция, больница, СМИ, страховая и т.д.)
- **Автообновления** — автоматическая проверка и установка обновлений, бета-канал с отдельным паролем, ручная проверка и красивый прогресс скачивания

### 🔄 Прочее
- **Поддержка всех фракций** — Полиция, ФБР, Армия, Правительство, Суд, Больница, Пожарные, СМИ, Мафия, Гетто, Тюрьма, Страховая компания
- **Кроссплатформенность** — полноценная работа на ПК и мобильных устройствах
- **Кастомизация команд** — переименование стандартных команд, отключение ненужных, поддержка нескольких аргументов, мгновенное применение изменений без перезапуска

## 📦 Установка

1. Убедитесь, что у вас установлен [MoonLoader](https://www.blast.hk/threads/13305/).
2. Скачайте последнюю версию хелпера со [страницы проекта](https://github.com/GreenTechYT/arizona-helper-unlimited) (или клонируйте репозиторий).
3. Поместите файл хелпера (`.lua`) в папку `moonloader/`.
4. Запустите игру — хелпер автоматически загрузит необходимые ресурсы (логотип, звуки, библиотеки).
5. Откройте меню хелпера командой `/helper` или через настроенный хоткей `F2`.

> 💡 При первом запуске хелпер предложит настроить основные параметры и принять пользовательское соглашение. Без принятия соглашения функции хелпера будут недоступны до следующего вызова меню.

## ⌨️ Команды

| Команда | Описание |
|---------|----------|
| `/helper` | Открыть главное меню хелпера |
| `/hm [ID]` | Быстрое меню взаимодействия с игроком |
| `/lm [ID]` | Лидерское фаст-меню (9/10 ранг) |
| `/edgo` | Система пробива личности по ЭБГО |
| `/pnv` | Надеть/снять очки ночного видения |
| `/irv` | Надеть/снять инфракрасные очки |
| `/cruise` | Адаптивный круиз-контроль |
| `/afind [ID]` | Авто-поиск игрока по GPS |
| `/sum [ID]` | Умная выдача розыска |
| `/tsm [ID]` | Умные штрафы |
| `/weapons` | Настройка RP-отыгровок оружия |
| `/stop` | Остановить отыгровку RP-команды |
| `/fixsize` | Сбросить размер интерфейса |
| `/members` | Кастомный список сотрудников |
| `/zeks` | Список заключённых (Правительство) |
| `/pum [ID]` | Умное повышение срока (Тюрьма) |
| `/wanteds` | Список розыска |
| `/patrool` | Меню патрулирования |
| `/sob` | Собеседование с игроком |
| `/dep` | Рация департамента |
| `/forensic` | Криминалистические экспертизы |
| `/spcar` | Спавн транспорта организации (9/10) |
| `/fcleaner [дни]` | Уволить неактивных сотрудников (9/10) |

> ⚠️ Доступность некоторых команд зависит от вашей фракции и ранга. Начиная с версии 1.7.0 команды можно переименовывать в редакторе стандартных команд.

## 📋 Требования

- **MoonLoader**
- **mimgui** (библиотека интерфейса)
- **mimgui_hotkeys** (опционально — для хоткеев)
- **mimgui_piemenu_mod** (опционально — для кругового меню)
- **MoonMonet** (опционально — для темы Custom)

> 📦 Библиотеки `arizona_backup.lua` и `arizona_crasher.lua` скачиваются автоматически при первом запуске.
